# Full-Stack Developer Team Portfolio

A responsive, single-page team portfolio built with plain HTML and CSS. No build step or package installation is required.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Choose **Other** as the framework preset, leave build and output settings empty, then deploy.

## Deploy to Render

1. Push this folder to a GitHub repository.
2. In Render, choose **New → Static Site** and connect the repository. The included `render.yaml` can also be used as a blueprint.
3. For manual setup, use an empty build command and `.` as the publish directory.

The portfolio includes six live project links, five supplied developer profiles, a team technology overview and a Shrestha Hospitals project callout. The team description reflects the supplied 5–6 developer range; only the five named profiles provided are listed.
